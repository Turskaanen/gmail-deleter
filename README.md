# Gmail Delete Tool

A simple Python-based command‑line tool for deleting Gmail emails using IMAP.
This script allows you to log in with your Gmail address and App Password, then delete emails based on:

A single sender

Multiple senders

Email subject

Or delete all emails (dangerous)

This tool is useful for cleaning up spam, bulk messages, or automating inbox maintenance.

🚀 Features
Login menu before accessing tools

Gmail App Password authentication

Delete emails by:

One sender

Multiple senders

Subject text

All emails in inbox

Clear and simple terminal interface

Works with any Gmail account that has IMAP enabled

🔐 Requirements
Gmail Settings
To use this tool, you must:

1. Enable 2‑Step Verification

2. Create a Gmail App Password

3. Use that App Password to log in

Google does not allow normal passwords for IMAP access.


# Usage: 

Use: python gmaildeleter.py
